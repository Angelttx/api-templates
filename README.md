# API Templates

Ready-to-use API templates for various use cases.

## Templates

- 🌐 **REST API** - Express.js REST API template
- 🔗 **Webhook Handler** - Receive and process webhooks
- 📡 **GraphQL** - Basic GraphQL server
- 🔐 **Auth API** - JWT authentication template

## Tech Stack

- Node.js
- Express
- MongoDB/PostgreSQL support
